# OJT Progress Tracker

A clean, modern task tracker for OJT progress monitoring. This project helps you add, manage, search, and update tasks with a sleek dashboard interface.

## Features

- Add tasks with title, category, date, status, and notes
- Search tasks instantly by title, category, status, or notes
- Mark tasks as complete, edit title, and delete tasks
- Responsive dark dashboard interface with polished card layout
- Persistent task storage using `localStorage`

## Files

- `File.html` - Main dashboard UI and markup
- `style.css` - Dark theme styling and layout for the tracker
- `script.js` - Task data handling, storage, and search logic

## Usage

1. Open `File.html` in your browser.
2. Use the form to add new tasks.
3. Search tasks using the search field.
4. Complete, edit, or delete tasks directly from the dashboard.

## Notes

- Tasks are saved locally in the browser and will persist between reloads on the same machine.
- For a fresh start, clear browser storage or delete tasks manually.
